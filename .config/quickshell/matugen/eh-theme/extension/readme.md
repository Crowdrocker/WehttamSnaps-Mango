# Dynamic Base16 EventShell Theme

A VSCode theme for [Event Horizon](https://github.com/Mattscreative/eventMaterialShell) (Quickshell).

## How It Works

1. Install this extension
2. Select one of the "Dynamic Base16 EventShell" themes in VSCode
3. Event Horizon automatically updates the theme files when you change themes.

The theme files are located in your VSCode extensions directory and are updated by matugen when generating new colors.

## Themes

- **Dynamic Base16 EventShell** - Follows your current light/dark mode
- **Dynamic Base16 EventShell (Dark)** - Always dark variant
- **Dynamic Base16 EventShell (Light)** - Always light variant
